# Метки триажа

Скиллы оперируют пятью ролями триажа. Эта таблица сопоставляет роли с реальными метками в трекере этого репо.

| Роль в mattpocock/skills | Метка в нашем трекере | Значение                                       |
| ------------------------ | --------------------- | ---------------------------------------------- |
| `needs-triage`           | `needs-triage`        | Мейнтейнеру нужно оценить issue                |
| `needs-info`             | `needs-info`          | Ждём уточнений от автора                       |
| `ready-for-agent`        | `ready-for-agent`     | Полностью описано, можно отдавать AFK-агенту   |
| `ready-for-human`        | `ready-for-human`     | Требует реализации человеком                   |
| `wontfix`                | `wontfix`             | Делать не будем                                |

Когда скилл упоминает роль (например, «повесить метку готовности для агента»), берите строку из правой колонки.

Правую колонку можно менять под свой словарь.

В Gitea-репо меток пока нет. При первом `/triage` создайте их:
`tea labels create --name needs-triage --color "#e4e669" --description "..."` и так далее для каждой строки таблицы.
